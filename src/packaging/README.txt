DF_RU — русский перевод Divine Frequency
========================================

Патч для полной версии Divine Frequency. Версия 1.0.8.
Демо-версия не поддерживается: у неё другие данные игры.

Установка
1. Распакуйте архив в любую папку.
2. Запустите install.cmd.
3. Установщик найдёт игру в Steam и во всех библиотеках из
   libraryfolders.vdf. Если игра не найдена, укажите папку, где
   лежат DivineFrequency.exe и DFSDSA.ipk3.
4. Запускайте игру обычным ярлыком или через Steam.

Установщик копирует один файл:

    <папка игры>\skins\DF_RU.wad

Это PK3-архив с расширением .wad; UZDoom автоматически загружает
.wad-файлы из папки skins. Конфиг игры не изменяется.

Удаление
Запустите uninstall.cmd или удалите вручную:

    <папка игры>\skins\DF_RU.wad

Сохранения
Патч переводит ACS-сообщения и скрипты карт. Из-за этого сохранения,
созданные в другой версии патча или без него, могут не загрузиться:
движок проверяет ACS-модули и данные карт. Начните новую игру; это
ограничение движка, а не ошибка установки.

Перевод использует общую папку сохранений игры. В информации о
сохранении могут быть русские названия карт и «Время:».

Если перевод не появился
- Проверьте, что файл установлен сюда:

      <папка игры>\skins\DF_RU.wad

- Проверьте, что игра запускается из полной версии, а не из демо.
- Закройте игру и запустите install.cmd ещё раз.

Для проверки можно запустить игру вручную:

    DivineFrequency.exe -file "<папка>\DF_RU.pk3"

Файлы
DF_RU.wad     — патч для папки skins
DF_RU.pk3     — тот же патч для запуска через -file
install.cmd   — установка
uninstall.cmd — удаление
find_game.ps1 — поиск установленной игры
README.txt    — этот файл
VERSION.txt   — версия патча

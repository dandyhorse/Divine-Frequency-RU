ACC 1.60 include files
=====================

`acc.exe` is included for reproducible Windows builds. `npm run setup` downloads it if the file is missing.

The compiler source and release are available at:

https://github.com/ZDoom/acc/releases/tag/1.60

ACC is an ACS compiler for ZDoom-compatible games. It is used here only to compile the translated map `SCRIPTS` lumps into `BEHAVIOR`.

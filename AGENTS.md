# AGENTS.md — правила работы над RU-переводом Divine Frequency

Этот файл читать первым при возобновлении работы. Здесь зафиксированы правила, текущее состояние и карта проекта.

## 1. Контекст

- Игра: `C:\Steam\steamapps\common\Divine Frequency`
- Движок: UZDoom (standalone).
- Контент игры: `DFSDSA.ipk3` (обычный ZIP/PK3, ~946 МБ).
- Ресурсы движка: `DF.pk3`.
- Рабочая папка: `C:\projects\RU_DivineFrequency`.
- Перевод собирается отдельным PK3: `dist/DF_RU.pk3`.
- Оригинальные файлы игры не изменяются.
- В проекте локальный git: пользователь сам правит неудачные строки в файлах перевода. Перед началом работы смотреть `git status`/`git diff`, чтобы увидеть его изменения и не откатывать их.
- Документация:
  - `ANALYSIS.md` — полный анализ;
  - `TRANSLATIONS.md` — таблица «что было → что стало»;
  - `README.md` — краткая инструкция.

- Контент вкладок «Оружие», «Бестиарий», «Карта»: `Language.Weapon` (кроме `DB_*`), `Language.Bestiary` и читаемые тексты `Language.Map` переведены.
- Оружие: переведены названия в UI (`Кулаки`, `Пистолет`, `Траншейное ружьё`, `Баллончик`, `Автомат`) и тексты `Language.Weapon`.

- Диалоги/имена: `dialoguefont` уже содержит кириллицу (0x400–0x4FF), перерисовывать не нужно; имена NPC идут через `RU_npcfont`, ответы — `RU_CONVO_FONT`. ## 4. Правила работы

1. **Итеративно и крупными блоками.** Сначала делаем большой объём, потом отчёт. Не дёргать игру на каждую мелочь.
2. **Не запускать игру и не делать скриншоты без явной просьбы.** Обычно достаточно собрать PK3, обновить документацию и отдать пользователю на проверку.
3. **Только перевод и вёрстка.** Не объяснять игровые механики и лор, если пользователь не просит.
4. **Не менять оригинальные файлы игры.** Не трогать `DFSDSA.ipk3`, `DF.pk3`, `DivineFrequency.exe` и основной `Documents\My Games\Divine Frequency\dfconfig.ini`.
5. **Работать через внешний PK3** `dist/DF_RU.pk3` и тестовые копии конфигов.
6. **Сохранять разметку:** `\cX`, `\c[Color]`, `\n`, `$ключи`, плейсхолдеры, пробелы/отступы.
7. **Язык:** добавлять `[ru]`-секции, не `[ru default]`. Английский `[enu default]` остаётся как fallback.
8. **Защищённые меню настроек:** не пытаться заменить их напрямую. Использовать новые `RU_`-меню и переключать на них вкладки.
9. **Шрифты:** папки `Fonts/*` загружаются атомарно. В патч класть полный набор: оригинальные PNG + `font.inf` + кириллица. Не добавлять только новые глифы.
10. **После изменений обновлять** `TRANSLATIONS.md` (через `tools/make_translation_md.py`), `README.md` и при необходимости `ANALYSIS.md`.
11. **Отчёт на русском:** что изменено, какие файлы, размер сборки, что проверить. После отчёта ждать команду пользователя.
12. **Не менять шрифт главного меню без подтверждения.** Пользователь решил, что оригинальный стиль — `BIGFONT`, а не `NewSmallFont`.
13. **Коммерческая игра:** личный перевод — личное использование; публикация патча требует разрешения правообладателя.
14. **Локальный git — источник правок пользователя.** Пользователь вручную исправляет строки перевода и коммитит/оставляет изменения в рабочей копии. Перед началом работы проверять `git status` и `git diff` (особенно по `work/`), учитывать эти правки и не откатывать их. Самому коммитить только по явной просьбе.
15. **Игровые сокращения не переводить.** `DMG`, `PT`, `HP`, `PSI` и подобные оставлять как в оригинале; не заменять русскими сокращениями вроде «УРН».

## 5. Сборка

Порядок:

```text
python tools/extract_sources.py
python tools/make_bigfont_cyr.py
python tools/make_ui_fonts_cyr.py
python tools/make_menudef.py
python tools/make_mapinfo.py
python tools/make_ui_overrides.py
python tools/build_pk3.py
python tools/make_translation_md.py
```

`make_bigfont_cyr.py` генерирует кириллицу для `bigfont` и `ACS_FONT` (профиль `ACS_FONT` также используется для `smallfont`).
`make_ui_fonts_cyr.py` генерирует `RU_DF_FONT`, `RU_ChatBoxFont`, `RU_CONVO_FONT` и `RU_npcfont`; превью — `work/preview_ui_font.png` и `work/preview_npc_font.png`.
`make_ui_overrides.py` создаёт переводы загрузки/сохранения и `[Нажмите любую кнопку]`. `Menu/tabmenu.zs` больше не создаётся.

## 6. Запуск и тестовые конфиги

- `test/run_test.cmd` или ярлык **Divine Frequency (RU)** — полный экран, `language=ru`.
- `test/run_original.cmd` или ярлык **Divine Frequency (Original)** — полный экран, `language=enu`.
- Конфиги: `test/dfconfig-test.ini`, `test/dfconfig-original.ini`; оба `vid_fullscreen=true`, 2560×1440.
- Основной `dfconfig.ini` не изменяется.
- Для диагностики компиляции можно запустить с `-stdout` и перенаправить вывод, но только если это действительно нужно.

## 7. Карта файлов

```text
ANALYSIS.md          полный анализ
TRANSLATIONS.md      таблица переводов (генерируется)
README.md            краткая инструкция
AGENTS.md            этот файл

source/              извлечённые текстовые исходники игры
  Language.*         оригинальные тексты
  MenuDef            оригинальное меню
  MapInfo            оригинальная карта/сложности
  ZScript/           исходники UI
  maps/              DIALOGUE/SCRIPTS карт

work/                рабочие исходники перевода
  MenuDef            полный перевод меню + RU_ -меню
  Language.RU        переводы DESC_*
  MapInfo            перевод сложности/карт/выхода
  ZScript/UI/...     оверрайды: шрифты, загрузка/сохранение, титульная подсказка
  Fonts/bigfont/     сгенерированная кириллица
  Fonts/ACS_FONT/    сгенерированная кириллица
  Fonts/BigUpper/    не хранится отдельно, собирается из bigfont
  Fonts/RU_DF_FONT/  DVFFN + кириллица для HUD/инвентаря/кодекса
  Fonts/RU_ChatBoxFont/, Fonts/RU_CONVO_FONT/  те же глифы с другими метриками
  Fonts/RU_npcfont/  золотая кириллица для имён NPC
  MenuDef.bigfont.bak — старый бэкап, не использовать без необходимости

dist/DF_RU.pk3       готовая сборка
tools/               скрипты извлечения/шрифтов/меню/сборки/таблицы
test/                конфиги, запуск, ярлыки, скриншоты
```

## 8. Следующие шаги

1. Дождаться проверки текущей сборки пользователем: шрифты HUD/инвентаря/кодека/имён NPC, диалоги и создание персонажа, предметы/улучшения/кодекс, карта, главное меню, вкладки, настройки, загрузка/сохранение, выход.
2. ACS-скрипты карт и оставшиеся технические/жёстко зашитые строки.
3. Стилевая вычитка пользователем; после его правок — повторная сборка.

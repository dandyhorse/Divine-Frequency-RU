# Извлечённые исходники

Здесь лежат текстовые материалы, извлечённые из `DFSDSA.ipk3` скриптом `tools/extract_sources.py`.

Что извлечено:

- `Language.*` — все языковые файлы игры;
- `MenuDef`, `MapInfo`, `CvarInfo.txt`, `FontDefs.txt`, `KeyConf.txt`, `ZScript.txt`;
- `ACS/*.acs` — исходники ACS-библиотек;
- `maps/<карта>/DIALOGUE` — текстовые USDF-диалоги карт;
- `maps/<карта>/SCRIPTS` — исходники ACS-скриптов карт;
- `maps/<карта>/BEHAVIOR.strings.txt` — printable-строки из скомпилированных `BEHAVIOR` (для поиска захардкоженного текста);
- `ZScript/`, `Menu/` — исходники UI и игровой логики;
- `engine/` — `language.csv`, `language.def` и шрифт Noto Sans с лицензией OFL.

Не извлекались:

- `TEXTMAP` карт (это десятки мегабайт геометрии, для перевода не нужны);
- спрайты, звуки, модели и прочие бинарные ассеты.

Это рабочие копии для перевода. Оригинальные файлы игры не изменялись.
